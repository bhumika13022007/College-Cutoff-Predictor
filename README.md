# 🎓 College Cutoff Predictor

An interactive Machine Learning web application that estimates college admission cutoffs based on university ID, admission year, category, seat type, and prediction type.

## 🚀 Live Demo

👉 **[Click here to use College Cutoff Predictor](https://cutoff-predictor-college.streamlit.app/)**

## 📌 About the Project

The College Cutoff Predictor is designed to help students explore estimated admission cutoffs using a trained Machine Learning model. Users can select their admission preferences and generate a prediction through a simple, interactive web interface.

The application uses a Scikit-learn Pipeline with a Random Forest Regressor to generate predictions from the selected inputs.

## ✨ Features

- 🎓 Interactive college cutoff prediction
- 🏛️ University ID selection through a dropdown
- 📅 Admission year selection
- 👥 Category selection
- 🎯 Seat type selection
- 📊 Prediction type selection
- 🤖 Trained Machine Learning model

- 🔍 View selected input details
- 🌙 Dark mode and light mode interface
- ☁️ Web deployment using Streamlit Community Cloud

## 🧠 Machine Learning Model

The application uses a trained Scikit-learn Pipeline containing:

- **Preprocessor:** `ColumnTransformer`
- **Categorical encoder:** `OneHotEncoder`
- **Regressor:** `RandomForestRegressor`

### Input Features

The model accepts the following five features:

1. `university_id`
2. `year`
3. `category`
4. `seat_type`
5. `figure_kind`

The categorical options are loaded from the trained model's encoder, helping the application use the available values from the original training process.

## ⚙️ Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/college-cutoff-predictor.git
```

Replace `YOUR_USERNAME` with your GitHub username.

### 2. Open the project directory

```bash
cd college-cutoff-predictor
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the environment

**Windows PowerShell:**

```powershell
.\venv\Scripts\Activate.ps1
```

### 5. Install dependencies

```bash
python -m pip install -r requirements.txt
```

### 6. Start the application

```bash
python -m streamlit run app.py
```

Open the local URL displayed in your terminal, usually `http://localhost:8501`.
